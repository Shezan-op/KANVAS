# Contributing to KANVAS

Thanks for helping make KANVAS better! Contributions of all kinds are welcome:
- New slide layout primitives
- Custom theme palettes and typography pairings
- Performance and rendering optimizations
- MCP tool enhancements

## Development Setup

```bash
git clone https://github.com/Shezan-op/KANVAS.git
cd KANVAS
npm install
npm run dev
```

Run checks before submitting PRs:
```bash
npm run typecheck
npm run build
```
